# 💻 Form 5 Extra Class Attendance System (PLASS5)
A web-based attendance system developed to ensure data is recorded more accurately and efficiently compared to manual recording.

> **Note:** The system's user interface (UI) and code outputs are in **Malay**

## Problem Statement:
Manual attendance recording using forms causes several problems:
* Inaccurate information, duplicate records, and missing data.
* Unclear handwriting.
* Leads to errors in attendance analysis and wastes time.

## Objectives:
1. To record student attendance for Form 5 extra classes.
2. To analyze and display attendance data clearly.

## Scope & Target Group:
* **Scope:** To record and display attendance records/analysis for Form 5 students only.
* **Target Group:** Only used by teachers (admin) and students.

## Evaluating Existing System (Manual):
* **Weaknesses:** Analysis process takes more time, and higher risk of errors during writing.
* **Strengths:** Can be accessed without relying on technology/internet, and low cost.

## New System Justification:
* Makes it easier for teachers to receive attendance analysis.
* Speeds up the process of recording and verifying attendance.

## Development Tools:
* **Languages:** PHP, JavaScript, HTML, CSS
* **Database:** MySQL
* **Environment:** XAMPP

---


### Local Setup:
1. Download or clone this repository into your XAMPP `htdocs` folder.
2. Import the `.sql` database file into `phpMyAdmin`.
3. Ensure the database connection settings in your PHP file match your local database configuration.
4. Open your browser and navigate to `localhost/your-folder-name`.
